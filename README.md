# Прогнозирование отмены бронирований в сети отелей
### Hotel Booking Cancellation Prediction

## Описание проекта

Этот проект посвящен разработке модели машинного обучения для прогнозирования вероятности отмены бронирования клиентом отеля.

Основная цель — не только создать точную модель классификации, но и оценить её экономическую эффективность для бизнеса, рассчитав влияние на ключевые показатели, такие как загрузка отелей и прирост дохода (**Incremental Revenue**).

Проект выполнялся в рамках учебного задания и включает полный цикл работы с данными: от исследовательского анализа до оценки и калибровки модели.

## Основные этапы

### 1. Постановка задачи и план решения

- Определение бизнес-задачи.
- Перевод бизнес-задачи на язык машинного обучения — бинарная классификация.
- Составление плана работы над проектом.

### 2. Исследовательский анализ данных (EDA)

- Анализ таблиц `bookings` (бронирования) и `reviews` (отзывы).
- Обработка пропусков, дубликатов и аномалий.
- Визуализация распределений признаков.
- Анализ корреляций с целевой переменной `booking_status`.

### 3. Предобработка данных и Feature Engineering

- Очистка данных: удаление дубликатов, исправление ошибок в категориальных признаках (`meal_plan`).
- Объединение таблиц `bookings` и `reviews` для получения информации о предыдущем опыте клиента — оценки и текста отзыва.
- Создание новых признаков:
  - `total_guests`
  - `total_nights`
  - `price_per_night`
  - `price_per_guest`
- Обработка текстов отзывов:
  - очистка текста;
  - удаление стоп-слов;
  - векторизация с помощью **TF-IDF**.

### 4. Обучение моделей

- Использование двух алгоритмов градиентного бустинга:
  - **CatBoost**
  - **LightGBM**
- Подбор гиперпараметров с помощью **Optuna**.
- Трёхфолдовая кросс-валидация.

### 5. Оценка и калибровка

- Выбор лучшей модели на основе метрики **Incremental Revenue (IR)**, отражающей экономическую эффективность модели.
- Калибровка модели.
- Поиск оптимального порога классификации для максимизации `IR`.

### 6. Анализ результатов

- Оценка качества модели на тестовой выборке.
- Анализ важности признаков (**Feature Importance**).
- Расчёт ключевых бизнес-показателей до и после внедрения модели.

## Результаты

### Наиболее важные признаки

Наиболее значимыми признаками для прогнозирования отмены бронирования являются:

- `days_until_checkin` — количество дней до заселения;
- `weekday_nights` — количество будних ночей;
- `previous_cancellations` — количество предыдущих отмен;
- `weekend_nights` — количество выходных ночей;
- `booking_value` — стоимость бронирования;
- `sales_channel` — канал бронирования.

### Лучшая модель

Лучшая модель — **CatBoost или LightGBM**. Окончательный выбор необходимо определить на основе значения метрики **Incremental Revenue (IR)**.

### Экономическая эффективность

Модель позволяет выявлять бронирования с высоким риском отмены, что даёт возможность более эффективно управлять загрузкой отеля и потенциально увеличить доход сети.
